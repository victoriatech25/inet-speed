# inet-speed — Victoria Tech 인터넷 속도측정

`victoria-tech.com`의 **[인터넷 속도측정]** 메뉴로 제공할 웹 페이지입니다. PC와 휴대폰 브라우저에서 앱 설치 없이 인터넷 품질을 진단합니다.

## 목적
- 단순 최고 속도가 아니라 **실제 체감 품질**을 보여줍니다: 다운로드·업로드 속도(90번째 백분위수), 대기 시간, 데이터 전송 중 대기 시간(버퍼블로트), 지터.
- 사용자의 **공용 IP, 통신사, 위치, 측정 서버 위치**를 함께 보여줍니다.
- 크기별 측정 분포(상자 그림)와 스트리밍·게임·화상 통화 품질 평가로 결과를 쉽게 해석하도록 돕습니다.
- **추가 비용 0원**으로 운영합니다.

## 구성 요약
| 항목 | 내용 |
| :--- | :--- |
| 측정 | Cloudflare 공개 라이브러리 [`@cloudflare/speedtest`](https://github.com/cloudflare/speedtest) + `speed.cloudflare.com` (자체 측정 서버 없음) |
| 화면 | Next.js(App Router) + TypeScript, 정적 빌드(`output: 'export'`), SVG 차트·지도 |
| 배포 | 기존 AWS EC2 웹 서버가 정적 파일 제공, 주소 `https://victoria-tech.com/speed` (예정) |
| 범위 밖 | 패킷 손실 측정(유료 TURN 필요), 서버 저장, 유료 API |

측정값은 "사용자 ↔ 가장 가까운 Cloudflare 엣지(한국은 대개 서울)" 구간의 품질입니다.
